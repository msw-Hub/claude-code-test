# 프로젝트 개요

## 목적

Claude Code 학습·실험용 저장소다. 현재 유일한 실제 산출물은 정적 웹페이지(`index.html`) 하나이며,
가상 인물("이준호")의 포트폴리오 페이지다. 페이지의 인물·이력·연락처·프로젝트 실적은 전부 예시이니
실제 정보로 대체하려 하지 말 것 (푸터에도 "가상"임을 명시해 두었다).

## 실행

빌드·번들·컴파일 단계가 없다. `index.html`을 브라우저로 직접 열면 그게 최종 결과물이다.

## 배포

GitHub Pages가 저장소 **루트**에서 서빙한다. 그래서 `index.html`은 반드시 루트의 진입점으로
유지되어야 한다 — 커밋 `c2fc5b6`에서 `test.html`을 `index.html`로 옮긴 것도 Pages가 루트의
`index.html`을 자동 진입점으로 삼기 때문이다. 파일명을 바꾸거나 하위 폴더로 옮기면 배포가 깨진다.

## 빌드 도구 부재 (주의)

- `package.json` 없음. npm 스크립트 없음.
- `tailwind.config.js`는 **비어 있고 Tailwind는 연결되어 있지 않다.** 향후 확장을 위해 자리만
  잡아둔 파일이다. 모든 스타일은 `index.html`의 `<style>` 블록에 있는 순수 CSS다.
  Tailwind를 실제로 쓰려면 빌드 파이프라인(PostCSS 등)부터 새로 구성해야 한다.
- `.claude/settings.json`에 `Bash(npm run *)`가 허용돼 있지만 이는 미리 열어둔 권한일 뿐,
  지금 실행할 npm 스크립트는 존재하지 않는다.
